# Журнал архитектурных решений

Журнал хранит значимые архитектурные решения о структуре коллекции, границах
и контрактах публикуемых навыков, а также форматах корпуса знаний.

Организационные решения и решения о структуре документации в этот журнал не
входят.

## Статусы

- `Предложено` — решение оформлено, но ещё не принято.
- `Принято` — решение действует.
- `Отклонено` — предложение рассмотрено и не принято.
- `Устарело` — решение больше не рекомендуется, замена не назначена.
- `Заменено` — решение заменено другой записью.

## Имена записей

Записи получают последовательные идентификаторы и имена файлов вида
`ADR-NNNN.md`, например `ADR-0001.md`. Заголовок записи содержит идентификатор
и краткое название решения.

Каждая запись описывает одно решение и содержит условие его пересмотра.
