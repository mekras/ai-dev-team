# Пользовательская документация

`user/` содержит руководства, учебные материалы и инструкции для человека,
который использует уже определённый продукт.

Пользовательская документация объясняет действие, ожидаемый результат и
следующий шаг. Она не заменяет источник продуктового поведения в разделах
`01–07`.
