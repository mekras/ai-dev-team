# Гипотезы

Раздел хранит проверяемые предположения, которые могут временно служить
основанием ограниченной работы. Гипотеза не становится требованием или
решением автоматически.

[Реестр гипотез](index.md) содержит только метаданные и ссылки на записи.
Каждая гипотеза хранится в отдельном файле со стабильным идентификатором и
связывается с вариантами использования, свидетельствами, требованиями и
решениями.

Результат проверки гипотезы передаётся в разделы `04–07` через обычные анализ,
оформление и принятие соответствующего материала.
