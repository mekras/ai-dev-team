# Документация проекта

Документация разделена по ответственности и порядку зависимости. Первые семь
разделов образуют продуктовую вертикаль. Ненумерованные области помогают найти,
использовать и сопровождать уже определённые материалы, но не задают порядок
формирования продукта.

## Продуктовая вертикаль

1. [01. Концепция](01-concept/README.md) — проблема, цель, результат и
   границы продукта.
2. [02. Варианты использования](02-use-cases/README.md) — цели действующих
   лиц и наблюдаемые результаты.
3. [03. Гипотезы](03-hypotheses/README.md) — временные проверяемые основания.
4. [04. Продукт](04-product/README.md) — ценность, состав и продуктовые
   решения.
5. [05. Требования](05-requirements/README.md) — проверяемые обязательства и
   критерии приёмки.
6. [06. Архитектура](06-architecture/README.md) — системные границы,
   зависимости и архитектурные решения.
7. [07. Детальное проектирование](07-design/README.md) — поведение,
   взаимодействие и предметные детали продукта.

Зависимость между разделами направлена слева направо:

```text
01 → 02 → 03 → 04 → 05 → 06 → 07
```

## Материалы вне вертикали

- [`meta/`](meta/README.md) — правила структуры, журналы договоров и
  служебные указатели.
- [`reference/`](reference/README.md) — справочные материалы, которые не
  задают обязательства продукта.
- [`user/`](user/README.md) — руководства и инструкции для пользователя.
- [`operations/`](operations/README.md) — разработка, сопровождение и рабочие
  процедуры.
- [`reports/`](reports/README.md) — производные отчёты и результаты проверок.

Корпус знаний проекта находится в отдельном корневом каталоге `knowledge/` и
сохраняет собственный договор.

## Маршрут чтения

- чтобы понять замысел, начните с [концепции](01-concept/README.md),
- чтобы найти основание решения о продукте, последовательно проверьте
  варианты использования, гипотезы и раздел продукта,
- чтобы проверить обязательство, откройте требование в разделе `05`,
- чтобы понять техническое устройство, перейдите из требований в раздел `06`,
- чтобы выполнить действие в готовом продукте, используйте раздел `user/`.

Записи решений не собраны в отдельном верхнем каталоге. Продуктовые решения
находятся в [04-product](04-product/README.md), архитектурные — в
[06-architecture](06-architecture/README.md), а решения о структуре
документации — в [meta/DDR](meta/DDR/DDR-001-documentation-dependency-order.md).
