# Реестр ADR проекта

Архитектурные решения по самому продукту `ai-dev-team`. Общая дисциплина и
шаблоны записей решений — в навыке `ait-decisions`
(`references/decision-workflow.md`, `references/decision-templates.md`);
архитектурная ось — в навыке `ait-architecture`
(`references/architectural-decisions.md`).

- [0001](0001-concepts-reconciliation-layer.md) — слой согласования понятий
  между корпусом и навыками. Статус: Принято.
- [0002](0002-cross-cutting-decision-records.md) — сквозная дисциплина записей
  решений в отдельном навыке. Статус: Принято.
- [0003](0003-rejected-decision-status.md) — статус отклонённого предложения.
  Статус: Принято.
- [0004](0004-product-evaluation-runner.md) — локальное средство сквозной
  сравнительной оценки. Статус: Принято.
- [0005](0005-cross-cutting-hypothesis-records.md) — сквозные записи гипотез в
  отдельных файлах. Статус: Принято.
- [0006](0006-ai-security-specialization.md) — специализация ИБ для
  использования и разработки ИИ. Статус: Принято.
- [0007](0007-dynamic-project-review-capabilities.md) — динамическое обнаружение
  возможностей полной проверки. Статус: Принято.
- [0008](0008-resumable-staged-project-review.md) — возобновляемая поэтапная
  проверка репозитория. Статус: Принято.
