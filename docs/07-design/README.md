# Детальное проектирование

Раздел описывает детали поведения и взаимодействия, которые ещё определяют
облик продукта: пользовательские потоки, интерфейсы, состояния,
дизайн-систему и предметные компоненты.

Архитектурные границы, системные зависимости и технические контракты остаются
источником в [06-architecture](../06-architecture/README.md). Пользовательские
инструкции о готовом поведении находятся в [user](../user/README.md).

Материалов раздела пока нет.
