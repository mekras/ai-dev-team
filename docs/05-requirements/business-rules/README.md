# Бизнес-правила

Этот каталог содержит канонические бизнес-правила продукта. Бизнес-правило
описывает предметную область, а не действие конкретной реализации. Требование,
автоматизирующее правило, хранится отдельно и ссылается на него.

Правила могут иметь проектный формат, но их семантическая классификация,
источник, границы и связи определяются [ФТ-44](../functional/ft-44.md).
