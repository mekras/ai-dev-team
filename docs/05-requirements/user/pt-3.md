# ПТ-3. Настройка только выбранных клиентских инструментов

[К списку требований](../README.md)

## Требование

Продукт должен создавать и изменять файлы только для тех клиентских
инструментов, которые явно выбрал пользователь. Поддержка других клиентских
инструментов или наличие их файлов и каталогов не должны приводить к их
настройке.

Если продукт не может однозначно определить выбранный клиентский инструмент из
явной команды или конфигурации, он должен задать один блокирующий вопрос до
создания или изменения клиентских файлов.

Требование не ограничивает пользователя одним клиентским инструментом. Каждый
инструмент должен быть выбран явно. Проверка публикуемого пакета для всех
поддерживаемых инструментов не считается таким выбором.

## Основание

Разные клиентские инструменты требуют отдельных файлов и каталогов. Настройка
всех поддерживаемых инструментов по умолчанию создаёт в проекте лишние файлы,
которые не нужны пользователю и усложняют сопровождение проекта.

[Концепция](../../01-concept/README.md) определяет продукт как подключаемую
команду, а
[ПТ-1. Путь пользователя от подключения к приёмке](pt-1.md) начинает рабочий
путь с подключения продукта. ПТ-3 ограничивает это подключение выбранными
пользователем инструментами.

## Реализация

- [README](../../../README.md) даёт отдельные команды установки для Claude и
  Codex. Каждая команда содержит один выбранный инструмент.
- [Подключение продукта через APM (ФТ-3)](../functional/ft-3.md) задаёт
  технический способ ограничить одну установку одной явно выбранной целью.
- [Настройка проекта](../../../.apm/skills/ait-setup/SKILL.md) продолжает работу
  только для однозначно выбранного клиентского инструмента.

## Проверка

ПТ-3 считается выполненным, если продукт создаёт и изменяет клиентские файлы
только для явно выбранных пользователем инструментов и не настраивает остальные
поддерживаемые инструменты по умолчанию.

1. При выборе Claude продукт настраивает файлы Claude и не создаёт файлы Codex.
2. При выборе Codex продукт настраивает файлы Codex и не создаёт файлы Claude.
3. Наличие файлов или каталогов нескольких инструментов не расширяет область
   настройки за пределы явного выбора пользователя.
4. Если явный выбор нельзя определить, продукт до изменения клиентских файлов
   задаёт один блокирующий вопрос.
5. Проверка пакета для всех поддерживаемых инструментов не меняет область
   настройки проекта пользователя.
6. Валидатор и сценарий `ait-setup-result-apm-installed-client-instructions`
   проверяют эти условия в составе команды `apm run tests`.
