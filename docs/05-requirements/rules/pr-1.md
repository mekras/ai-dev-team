# ПР-1. Префикс собственных навыков

[К списку требований](../README.md)

## Требование

Имена всех собственных навыков продукта начинаются с `ait-`. Навыки,
поставляемые зависимостями (например, `ai-` и `kc-`), сохраняют имена своих
источников.

Собственным считается каждый каталог непосредственно в `.apm/skills/`. Навык
зависимости не копируется туда для переименования: APM устанавливает его из
объявленного пакета под исходным именем. Локальный адаптер или обёртка считается
собственным навыком и получает имя `ait-*`.

## Основание

[КАЧ-2](../quality/kach-2.md) отделяет переносимое ядро от клиентских адаптеров.
Пакет одновременно устанавливает собственные навыки и зависимости с
пространствами имён `ai-` и `kc-`, поэтому префикс `ait-` предотвращает
неоднозначность происхождения без переименования внешних примитивов.

## Реализация

- `tools/validate-apm-package-structure.py` проверяет все фактические каталоги в
  `.apm/skills/`, а не только обязательный перечень.
- `apm.yml` хранит исходные ссылки на пакеты зависимостей, `apm audit --ci`
  проверяет установленный состав и отсутствие дрейфа.

## Проверка

1. `apm run tests` проходит, если каждый каталог `.apm/skills/` начинается с
   `ait-` и содержит `SKILL.md`.
2. Отрицательная проверка добавляет неизвестный каталог без префикса `ait-` и
   получает отказ независимо от обязательного перечня навыков.
3. `apm audit --ci` подтверждает исходные имена навыков зависимостей.
