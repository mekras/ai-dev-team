# ФТ-69. Подключение существующего реестра ресурсов

[К списку требований](../README.md)

## Требование

При наличии реестра ресурсов целевого проекта продукт должен использовать
его как источник сведений, необходимых текущей задаче. Подключение должно
различать систему, способ доступа и механизм подключения, сохраняя конкретные
адреса, разрешения и настройки у потребителя. Продукт должен устанавливать
доступность требуемого ресурса в пределах полученных полномочий.

Продукт не должен требовать переноса существующего реестра в собственный формат
или создания реестра для задачи, которая в нём не нуждается. Запись о ресурсе
сама по себе не должна считаться разрешением на внешнее действие.

## Основание

[Концепция продукта](../../01-concept/README.md) требует доступности нужных
знаний при ограничении сложности. [ПР-3](../rules/pr-3.md) сохраняет границу
между переносимым ядром и настройками потребителя.

## Связи

- [ФТ-67](ft-67.md) позволяет обнаружить существующий реестр при настройке.
- [ФТ-68](ft-68.md) сохраняет область правил и полномочий.

## Реализация

[Справка настройки рабочего места][workspace] задаёт подключение указателем
и получение только нужных записей существующим средством потребителя.

[workspace]: ../../../.apm/skills/ait-setup/references/workspace.md

## Проверка

1. Существующий реестр подключается указателем без копирования адресов
   и разрешений в переносимое ядро.
2. При недоступном канале доступа названы ограничение и зависимое действие.
3. Обнаруженная запись не вызывает внешнюю запись или отправку сообщения
   без действующего разрешения.
4. Отсутствие реестра не блокирует задачу, которой он не требуется.
