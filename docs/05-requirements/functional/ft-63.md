# ФТ-63. Свидетельства выполнения правки

[К списку требований](../README.md)

## Требование

При возврате результата порученной правки артефакта продукт должен передать
ссылку на применённый раздел источника формы и свидетельства требуемой проверки.
Невыполненные проверки и ограничения их охвата указываются явно.

Родитель проверяет применимость указанного правила и соответствие фактического
результата этому правилу. Наличие ссылки или заявления о выполнении проверки
само по себе не подтверждает соответствие. Неполный результат проходит порядок
приёмки по [ФТ-2](ft-2.md).

## Основание

[Концепция](../../01-concept/README.md) требует проверяемого результата.
Связь между применённым правилом, изменённым артефактом и проверкой позволяет
обнаружить перенос неподходящего оформления и неполноту исполнения поручения.

## Связи

- Дополняет [ФТ-62. Источник формы в поручении на правку](ft-62.md).
- Уточняет [ФТ-2. Контроль качества результата](ft-2.md).

## Реализация

Возврат свидетельств и их приёмка заданы в [договоре маршрутизации][routing].
Используется существующий контроль результата без нового статуса или этапа.

## Проверка

1. Результат содержит изменённый артефакт или ссылку на него, применённый раздел
   правила и наблюдаемый результат требуемой проверки.
2. Общий отчёт «оформление исправлено» без источника и свидетельств проверки
   не принимается как готовый результат.
3. Ссылка на правило при несоответствующем ему артефакте не закрывает приёмку.
4. Проверка подготовленного текста не выдаётся за проверку сохранённого
   артефакта. Неисполненная проверка обозначается как ограничение.
