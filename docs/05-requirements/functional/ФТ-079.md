# ФТ-79. Порядок работы с учётом условий задачи

[К списку требований](../README.md)

## Требование

Продукт должен выбирать порядок работы с учётом условий задачи. Он не должен
ставить её выполнение в зависимость от предпосылок, которые в этих условиях
не требуются.

## Основание

[ПТ-1. Путь пользователя от подключения к приёмке](../user/pt-1.md) требует,
чтобы продукт самостоятельно определял рабочий маршрут. Владелец продукта
выделил учёт условий задачи в отдельное обязательство.

## Реализация

[Сквозное выполнение задачи][task-execution] описывает выбор этапов по условиям
задачи.
