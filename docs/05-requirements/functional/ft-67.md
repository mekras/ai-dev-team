# ФТ-67. Границы рабочего места

[К списку требований](../README.md)

## Требование

При настройке работы над несколькими репозиториями продукт должен установить
границы рабочего корня, участвующих репозиториев и общих пакетов, используя
существующие описания потребителя и ранее принятые параметры. Рабочий корень
может находиться вне системы управления версиями. Репозиторий и целевой проект
не должны автоматически считаться одной и той же границей.

Результат должен указывать источники общих правил, местных спецификаций,
графов влияния и сведений о зависимостях в согласованной области. Общий пакет
должен иметь явных потребителей и область применения. Расположение рядом
не должно само по себе означать зависимость или наследование правил.

Для работы в одном репозитории продукт должен сохранять прежний маршрут без
обязательного описания рабочего места или обследования соседних каталогов.

## Основание

[Концепция продукта](../../01-concept/README.md) требует организовывать
необходимую сложность через ясные границы и доступные знания. Поддержка
нескольких репозиториев должна сохранять самостоятельность их сопровождения.

## Реализация

[Настройка рабочего места][workspace] расширяет существующий `ait-setup`.
Параметры потребителя сохраняются указателями на существующие источники.

[workspace]: ../../../.apm/skills/ait-setup/references/workspace.md

## Проверка

1. Рабочий корень вне Git с двумя репозиториями получает явные границы
   без создания общего репозитория и копии местных спецификаций.
2. Найденное описание рабочего места используется повторно. Имена каталогов
   и схема пакетов конкретного потребителя не становятся обязательными.
3. При запросе в одном репозитории соседние каталоги не обследуются без
   основания из задачи или объявленных зависимостей.
