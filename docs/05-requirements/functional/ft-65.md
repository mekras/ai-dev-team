# ФТ-65. Вердикт и состояние спецификации

[К списку требований](../README.md)

## Требование

Для каждого проверенного замечания продукт должен независимо определить
вердикт по поведению и достаточность спецификации. Вердикт различает ошибку,
отсутствие ошибки, недостаток свидетельств и необходимость продуктового
решения. Оценка спецификации различает заданное поведение, неполноту,
двусмысленность и противоречие.

Вердикт должен опираться на применимые основания ожидаемого поведения и
свидетельства фактического. Молчание документации само по себе не доказывает
ни наличие, ни отсутствие ошибки. Если ошибка установлена по другим
применимым требованиям, принятым ограничениям или решениям, пробел
спецификации не должен отменять этот вердикт. При отсутствии достаточного
основания продукт должен сохранить неизвестность или передать продуктовый
выбор человеку.

## Основание

[Концепция продукта](../../01-concept/README.md) требует проверяемых результатов
и сохраняет за человеком определение замысла. Независимые оценки позволяют
выявить одновременно ошибку поведения и пробел спецификации без подмены
решения человека предположением агента.

## Проверка

1. В одном сообщении замечания могут получить разные вердикты. Общий вердикт
   не скрывает их различий.
2. Установленная ошибка и неполная спецификация сохраняются в результате
   одновременно, со своими основаниями.
3. При молчании документации и отсутствии других оснований продукт не объявляет
   поведение правильным или ошибочным по собственному усмотрению.
4. Вердикт об отсутствии ошибки имеет положительное основание ожидаемого
   поведения и свидетельство его соответствия этому основанию.
