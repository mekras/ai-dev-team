# ФТ-36. Акцент на значении

[К списку требований](../README.md)

## Требование

Если в тексте для человека пара «свойство: значение» использует
жирное начертание для акцента, продукт должен выделять значение,
а не название свойства.

Это требование не обязывает выделять каждое значение. Акцент нужен,
когда он помогает быстро распознать состояние, приоритет, результат или
другое значимое для читателя значение.

## Основание

Явное решение пользователя от 3 августа 2026 года: внимание читателя
должно привлекать значение свойства, а не его название.

## Связи

- Уточняет [КАЧ-4. Понятность текстов для
  человека](../quality/kach-4.md): визуальный акцент должен помогать быстро
  увидеть значимое сведение.
- Дополняет [ФТ-33. Ссылки рядом с
  упоминаниями](ft-33.md): оба требования сокращают поисковую работу
  читателя в текущем фрагменте.

## Реализация

- [Инструкция подключения][connection] задаёт общее правило для текстов
  продукта.
- [Техническое письмо](../../../.apm/skills/ait-writing/SKILL.md)
  проверяет акценты в документах.
- [Шаблоны вариантов использования][templates] показывают правило в
  карточке сценария.

## Проверка

ФТ-36 считается выполненным, если продукт выделяет значения в парах
«свойство: значение» и не создаёт лишние акценты.

1. Пример `Статус: **Черновик**` соответствует требованию.
2. Пример `**Статус:** Черновик` классифицируется как ошибка.
3. Отсутствие жирного начертания допустимо, если акцент не нужен.
