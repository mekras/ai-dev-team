# ФТ-3. Подключение продукта через APM

[К списку требований](../README.md)

## Требование

Продукт должен подключаться к целевому проекту штатными средствами менеджера
пакетов APM.

Каждая команда первичной установки должна содержать ровно одну явную цель:
`--target claude` или `--target codex`. Значение `all`, список целей и команда
без `--target` не являются пользовательским способом подключения. Ограничение
одной команды одной целью не запрещает пользователю явно подключить другой
клиентский инструмент отдельным поддерживаемым действием.

Проверка публикуемого пакета может охватывать все поддерживаемые цели, но не
должна создавать их клиентские файлы в целевом проекте пользователя.

## Основание

[Концепция](../../01-concept/README.md) определяет продукт как подключаемую
команду.
[ПТ-3. Настройка только выбранных клиентских инструментов](../user/pt-3.md)
требует не создавать файлы для инструментов, которых пользователь не выбирал.

## Связи

- Обеспечивает подключение продукта пользователем по
  [ПТ-1. Пути пользователя от подключения к приёмке](../user/pt-1.md).
- Ограничивает создаваемые клиентские файлы по
  [ПТ-3. Настройке только выбранных клиентских инструментов](../user/pt-3.md).
- Логический контракт подключения уточнён в [ФТ-4](ft-4.md).
- Число действий пользователя оценивается по [КАЧ-1](../quality/kach-1.md).

## Реализация

- Пакет объявлен в [apm.yml](../../../apm.yml) с внутренней целью
  `agent-skills` и клиентскими целями `claude` и `codex`. Внутренняя цель не
  меняет пользовательскую команду подключения.
- [README](../../../README.md) содержит команды `apm install` для обеих целей и
  следующий шаг «Настрой проект».
- [ait-setup](../../../.apm/skills/ait-setup/SKILL.md) завершает настройку уже
  установленного продукта в целевом проекте.

## Проверка

ФТ-3 считается выполненным, если каждая пользовательская команда подключения
через APM содержит одну явную клиентскую цель и не создаёт файлы других
поддерживаемых клиентских инструментов.

1. Команды в README используют пакет `mekras/ai-dev-team`, версию из `apm.yml` и
   ровно одну явную цель: `claude` или `codex`.
2. После установки в целевом проекте есть прямая зависимость
   `mekras/ai-dev-team`, а в выбранном клиенте доступен навык `ait-setup`.
3. Одна команда подключения не создаёт клиентские файлы для невыбранной цели.
4. Пробная упаковка для всех поддерживаемых целей не меняет выбор пользователя в
   целевом проекте.
5. `apm run tests` проверяет согласованность команд подключения с версией
   пакета, компиляцию и пробную упаковку.
