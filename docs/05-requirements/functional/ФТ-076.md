# ФТ-76. Проверка записи решения перед показом

[К списку требований](../README.md)

## Требование

До показа записи решения человеку агент продукта должен передать её на
проверку отдельному исполнителю, которому не передан ход работы над записью.
Исполнитель получает запись, правила записей решений и доступ на чтение к
документации проекта. Правила записей решений — это навык продукта и правила
журнала целевого проекта. Ход работы над записью исполнитель не получает.
Проверяя журнал, агент применяет критерии к каждой записи. Исполнитель
возвращает:

- фрагменты с дефектами по [КАЧ-6](../quality/kach-6.md), с нарушенным
  критерием для каждого. Проверка охватывает лишние сведения, модальность
  всей записи, ясность обоснования и последствий, границу обязательств,
- вопрос, на который запись отвечает по собственному тексту.

Автор должен разобрать каждую находку: исправить запись либо сохранить
фрагмент и назвать причину. Перед показом агент сверяет разбор с итоговой
версией. Сохранённый фрагмент и причину его сохранения агент показывает
человеку вместе с записью.

Если отдельный исполнитель недоступен или его запуск не удался, агент
выполняет ту же проверку сам и при показе записи сообщает, что проверка не
независимая. Прямое требование отдельного исполнителя со стороны
пользователя или правил целевого проекта сохраняется.

Проверка не заменяет второй взгляд и принятие записи по
[ФТ-9](ФТ-009.md).

## Основание

Решение владельца продукта от 24.11.2026 по разбору повторяющихся дефектов
записей решений. Автор записи видел подробности реализации в ходе работы и
считает их уместными. Правка автором после замечания человека сохраняла те же
дефекты, хотя правила записи были ему доступны. Читатель без хода работы
оценивает запись так же, как её будущий читатель.

## Связи

- [КАЧ-6](../quality/kach-6.md) задаёт критерии проверки текста читателем.
- [ФТ-7](ФТ-007.md) задаёт общую форму записи решения.
- [ФТ-9](ФТ-009.md) задаёт принятие записи до действия.

## Реализация

- [ait-decisions](../../../.apm/skills/ait-decisions/SKILL.md) требует
  проверку перед показом записи человеку.
- [documentation-reader](../../../.apm/agents/documentation-reader.agent.md)
  выполняет проверку с профилем читателя, который знает проект, но не
  участвовал в работе над записью.
