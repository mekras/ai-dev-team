# ФТ-33. Ссылки рядом с упоминаниями

[К списку требований](../README.md)

## Требование

При создании и проверке проектной документации продукт должен ставить ссылку на
другой документ прямо при его содержательном упоминании. Если абзац упоминает
несколько документов, читатель должен получить переход к каждому из них в том
же абзаце.

Общий раздел «Связанные документы» и ссылка в другой части страницы не заменяют
локальный переход. Повторная ссылка допустима, если она избавляет читателя от
поиска перехода вне текущего абзаца.

Ссылку по возможности встраивают в нужные слова предложения, если по ним
понятно назначение перехода. Иначе рядом добавляют ссылку с узнаваемым
названием документа или объекта, например в скобках. Если такого известного
читателю названия нет, используют имя файла или путь, не придумывая подпись.
Общеупотребительное слово подходит для ссылки, когда в контексте однозначно
указывает на нужный документ. Повторять один переход внутри тесно связного
фрагмента следует только при пользе для читателя.

## Основание

Уточнение пользователя от 3 ноября 2026 года и поручение «Делай»: сохранять
естественное чтение и выбирать текст ссылки по знаниям читателя.

Явное решение пользователя от 2 августа 2026 года: обычная область внимания
читателя ограничена текущим абзацем, поэтому поиск ссылки по всему документу
создаёт лишнюю навигационную работу.

## Связи

- Уточняет [КАЧ-4. Понятность текстов для
  человека](../quality/kach-4.md): связанный документ должен быть доступен из
  места, где он нужен читателю.
- Дополняет [ФТ-23. Концепция как главный ориентир](ft-23.md): упоминание
  концепции в проектном тексте должно давать непосредственный переход к ней.

## Реализация

[Техническое письмо](../../../.apm/skills/ait-writing/SKILL.md) проверяет
локальные переходы при сборе контекста документации и считает отсутствующую
ссылку дефектом.

## Проверка

ФТ-33 считается выполненным, если читатель может перейти к каждому
содержательно упомянутому документу из того же абзаца.

1. Упоминание одного документа содержит локальную ссылку на него.
2. Упоминание нескольких документов содержит отдельный переход к каждому.
3. Наличие общего перечня связанных документов не скрывает пропущенную ссылку
   в содержательном абзаце.
4. Проверка не требует бессмысленно ссылать каждое повторное слово.
