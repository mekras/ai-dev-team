# ФТ-55. Выполнение навыков без подагентов

[К списку требований](../README.md)

## Требование

При отключённых или недоступных подагентах продукт должен продолжать
профильную работу и доступные проверки основным агентом. Применение навыка,
включая аудит собственных изменений, не требует отдельного исполнителя само
по себе. Самопроверка должна быть названа явно вместе с охватом,
свидетельствами и ограничениями.

Неуспешный запуск или отклонённый результат не разрешает использовать
непринятый ответ и не препятствует самостоятельному продолжению доступной
работы. Продукт не должен требовать включить подагентов ради этого продолжения.

Прямое требование отдельного исполнителя со стороны пользователя, действующих
правил проекта или предмета задачи сохраняется. Оно ограничивает только
зависимое действие или вывод. Самопроверка не подтверждает независимость,
работу делегирования, устранение дефектов или недоступные свидетельства.

## Основание

Владелец продукта 15 октября 2026 года указал, что отсутствие возможности
запуска подагента в целевом проекте не должно мешать выполнению навыков,
и поручил устранить оставшиеся ограничения после обновления зависимости.
[Концепция](../../01-concept/README.md) требует соразмерного контроля без
ненужного усложнения процесса.

## Связи

- Сохраняет контроль качества из [ФТ-2](ft-2.md).
- Применяется при настройке по [ФТ-18](ft-18.md).

## Реализация

- `ait-setup` использует правило выбора исполнителя из зависимости
  `ai-agent-supervisor`, включая самостоятельный аудит правил.

## Проверка

1. При отключённых подагентах основной агент выполняет аудит изменённого
   `AGENTS.md`, обозначает самопроверку и продолжает настройку.
2. После прерванного запуска доступная работа продолжается без использования
   непринятого результата и без автоматического повторного запуска.
3. Прямое внешнее требование независимой проверки не выдаётся за выполненное
   после самопроверки. Найденный дефект сохраняет собственный блокер.
