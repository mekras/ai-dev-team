# ФТ-1. Приоритет правил целевого проекта

[К списку требований](../README.md)

## Требование

Если применимое правило продукта противоречит применимому правилу целевого
проекта, продукт должен следовать правилу целевого проекта.

## Основание

Согласно принципу [02. Хозяин — барин][principle-02], пользователь определяет,
как работать в своём проекте. Если при конфликте продукт применит собственное
правило вместо правила целевого проекта, он навяжет пользователю свой порядок
работы.
