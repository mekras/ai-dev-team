# ФТ-62. Источник формы в поручении на правку

[К списку требований](../README.md)

## Требование

При передаче правки артефакта исполнителю продукт должен включить в поручение
доступный источник требований к форме артефакта и требуемую проверку результата.
Источник указывается как конкретный навык, правило или шаблон с расположением
применимого раздела. Исполнитель должен открыть его до правки.

Если источник неизвестен, продукт сначала поручает его поиск. Недоступность
источника или неразрешённое противоречие останавливают зависимую правку.
Пример оформления из поручения сам по себе не заменяет источник формы.

## Основание

[Концепция](../../01-concept/README.md) требует доступности необходимых знаний
при работе с отдельной частью проекта и воспроизводимого качества результата.
Передача источника формы позволяет исполнителю применять правила целевого
артефакта без догадки по оформлению сообщения родителя.

## Связи

- Уточняет [ФТ-1. Единый контур агентной разработки](ft-1.md).
- Применяет [ФТ-26. Раннее назначение проверок](ft-26.md) к правке артефакта.
- Дополняется [ФТ-63. Свидетельства выполнения правки](ft-63.md).

## Реализация

Порядок передачи и поиска источника задан в [договоре маршрутизации][routing].
[Менеджер проекта][manager] применяет этот договор при передаче работы.

## Проверка

1. Поручение с известным источником содержит его точное расположение,
   требуемую проверку и указание открыть источник до правки.
2. При неизвестном источнике первым поручением становится его поиск.
3. Недоступный или противоречивый источник останавливает зависимую правку.
4. Если пример родителя расходится с явно заданным правилом целевого
   артефакта, исполнитель применяет правило. Явное изменение правила проходит
   обычное согласование, а не выводится из примера.
