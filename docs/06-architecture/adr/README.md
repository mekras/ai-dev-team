# Реестр ADR проекта

Архитектурные решения по самому продукту `ai-dev-team`. Общая дисциплина и
шаблоны записей решений — в навыке `ait-decisions`
(`references/decision-workflow.md`, `references/decision-templates.md`);
архитектурная ось — в навыке `ait-architecture`
(`references/architectural-decisions.md`).

- Путь журнала: `docs/06-architecture/adr/`.
- Идентификатор: `ADR-NNNN`.
- Статусы: `Предложено`, `Принято`, `Отклонено`, `Устарело`, `Заменено`.

- [0001](0001-canonical-product-conceptual-model.md) — канонический понятийный
  аппарат продукта. Статус: Принято.
- [0002](0002-cross-cutting-decision-records.md) — сквозная дисциплина записей
  решений в отдельном навыке. Статус: Принято.
- [0003](0003-rejected-decision-status.md) — статус отклонённого предложения.
  Статус: Принято.
- [0004](0004-product-evaluation-runner.md) — локальное средство сквозной
  сравнительной оценки. Статус: Заменено решением 0013.
- [0005](0005-cross-cutting-hypothesis-records.md) — сквозные записи гипотез в
  отдельных файлах. Статус: Принято.
- [0006](0006-ai-security-specialization.md) — специализация ИБ для
  использования и разработки ИИ. Статус: Принято.
- [0007](0007-dynamic-project-review-capabilities.md) — динамическое обнаружение
  возможностей полной проверки. Статус: Принято.
- [0008](0008-resumable-staged-project-review.md) — возобновляемая поэтапная
  проверка репозитория. Статус: Заменено решением 0009.
- [0009](0009-impact-prioritized-project-review.md) — выбор следующей работы
  полной проверки по ожидаемому влиянию. Статус: Заменено решением 0010.
- [0010](0010-concept-first-project-review.md) — обязательная первая проверка
  концепции перед динамическим выбором остальных областей. Статус: Принято.
- [0011](0011-knowledge-corpus-second-project-review.md) — обязательная вторая
  проверка корпуса знаний после концепции. Статус: Принято.
- [0012](0012-project-impact-graph.md) — единый граф возможного влияния для всей
  работы проекта. Статус: Принято.
- [0013](0013-product-evidence-levels.md) — уровни свидетельств о свойствах
  продукта. Статус: Принято.
- [0014](0014-project-ontology-and-representations.md) — граф проекта как
  модель артефактов и представлений. Статус: Принято.
