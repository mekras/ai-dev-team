# Служебная документация

`meta/` находится вне продуктовой вертикали. Здесь хранятся правила структуры,
договоры журналов, решения о самой документации, индексы и служебные
указатели.

Главное решение о порядке зависимости —
[DDR-001](DDR/DDR-001-documentation-dependency-order.md). Конкретные разделы
закреплены в [DDR-002](DDR/DDR-002-documentation-sections.md).
