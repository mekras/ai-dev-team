# Реестр DDR проекта

Documentation Decision Record (DDR) фиксирует значимые решения о структуре,
навигации и порядке зависимости документации проекта.

## Соглашение

- Путь журнала: `docs/meta/DDR/`.
- Идентификатор: `DDR-NNN`.
- Имя файла: `DDR-NNN-<краткое-название>.md`.
- Шаблон: простая форма Найгарда.
- Статусы: `Предложено`, `Принято`, `Отклонено`, `Устарело`, `Заменено`.
- Реестр и договор журнала сопровождаются в этом файле.

## Реестр

- [DDR-001](DDR-001-documentation-dependency-order.md) — порядок зависимости
  документации, статус: `Принято`.
- [DDR-002](DDR-002-documentation-sections.md) — конкретные разделы
  документации, статус: `Принято`.
