# Как добавить в корпус файл без добавления в Git

Иногда бывает необходимо добавить в качестве источника файл, который не должен
попасть в Git: книга, скан, аудио или видео с ограниченными правами,
чувствительными данными или просто слишком большие, чтобы помещать в Git.

Напишите агенту такой запрос:

```text
Добавь в корпус знаний файл /путь/к/файлу как локальный источник без добавления полного файла в Git.
```

Либо можно положить файл в корпус вручную в папку конкретного источника.
По умолчанию это `data/<source>/local/`, но в конкретном проекте можно
настроить другую структуру папок в `corpus.yml`.

Если известны происхождение файла, лицензия, условия использования или причина
ограничения, добавьте их к запросу обычным текстом. Например: «Файл получен из
личной библиотеки, права на публикацию полного текста не подтверждены».

Агент оформит файл как источник корпуса: создаст или обновит карточку
источника, выберет локальную стратегию хранения, запишет переносимый локатор,
метаданные, хэш и ограничения. Полный файл останется в локальном слое проекта,
а в Git попадут только переносимые файлы корпуса: карточка источника, индекс
единиц при необходимости, метаданные и разрешённые производные артефакты.

Если сведений о происхождении, доступе или месте учёта источника не хватит,
агент задаст уточняющий вопрос до изменения корпуса.
