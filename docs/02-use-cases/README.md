# Варианты использования

Раздел описывает цели действующих лиц, границы продукта и наблюдаемые
результаты. Эти записи служат продуктовым основанием для раздела
[04-product](../04-product/README.md).

Действующие лица описаны как [персонажи](personas/README.md) — проектировочные
модели представителей целевых групп с их целями и контекстом.

Варианты использования разделены по уровню обобщения. Каждый уровень имеет
собственный индекс и собственную нумерацию.

- [UC-GEN. Обобщённые цели](01-general/README.md)
- [UC-SUM. Обзорные цели](02-summary/README.md)
- [UC-USR. Цели пользователя](03-user/README.md)
- [UC-SUB. Подфункции](04-subfunctions/README.md)

Продуктовый вариант использования отвечает на вопрос о цели и результате.
Инструкция о том, как выполнить действие в готовом продукте, относится к
[пользовательской документации](../user/README.md).
