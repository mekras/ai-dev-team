# Персонажи

Индекс персонажей продукта. Персонаж — конкретная воображаемая модель
пользователя. Отличительный набор целей и мотивов определяет состав персонажей,
а контекст и существенные характеристики делают каждого персонажа пригодным для
принятия проектных решений.

Персонажи находятся здесь потому, что они задают действующих лиц и цели для
[вариантов использования](../README.md). Один персонаж может участвовать в
вариантах использования разных уровней.

Как источник аналитического разбора персонаж помогает формулировать
проектировочные гипотезы о пользователе. Он не предоставляет новых данных, не
отвечает на вопросы и не принимает решения. Для проверки гипотезы аналитик
обращается к реальному информанту или организует сбор данных.

Имя персонажа — его естественный идентификатор. Используй его в документах и
ссылках. Имя файла записывай строчными латинскими буквами, передавая имя
персонажа без кодового идентификатора.

- [Игорь](igor.md) — ведёт программный проект с помощью агентов ИИ,
  основной персонаж типового сценария.

## Ограничение набора

Текущий набор начинается с правдоподобных рабочих приближений. Происхождение
целей и характеристик проверяется в рабочем анализе и отчётах влияния. Карточка
при этом остаётся описанием человека, а не протоколом происхождения каждого
сведения. Концепция продукта, требования и устройство продукта могут задавать
предметный контекст, но сами по себе не доказывают личные цели человека.

Полевого исследования пользователей продукта не проводилось. Это ограничивает
уверенность в наборе и оставляет приоритеты персонажей решением владельца, но не
мешает применять конкретного и внутренне согласованного персонажа в
проектировании. Наблюдения и интервью могут уточнить, разделить или объединить
рабочие модели.
