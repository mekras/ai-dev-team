# КАЧ-6. Качество записи решения

[К списку требований](../../requirements.md)

## Требование

Запись решения, в дополнение к [КАЧ-5](kach-5.md), проверяема по пространству
вариантов:

- пространство вариантов покрывает спектр возможностей, включая крайние точки;
  «дыра» между вариантами или недостаток, для которого нет варианта без этого
  недостатка, — признак неполного анализа;
- достоинства и недостатки вариантов согласованы между собой: формулировка
  недостатка одного варианта проверяется на наличие варианта, свободного от
  него;
- варианты не выдумываются: если выбор был безальтернативным, запись честно
  говорит об этом и объясняет почему;
- контекст кратко фиксирует наблюдаемую ситуацию, проблему, её влияние и только
  те ограничения, которые меняют сравнение вариантов; оценка вариантов, решение,
  последствия, проверка, доказательство вида журнала, технические подробности
  без влияния на выбор и внутренняя работа агента в него не входят;
- материалы, не влияющие на выбор, в тело записи не входят.

## Основание

Решение владельца; корпус знаний — `SAHP`, `ADRG` (практики рецензирования
решений).

## Связи

- [КАЧ-5](kach-5.md) задаёт лаконичность без потери смысла.
- [ФТ-7](../functional/ft-7.md) задаёт общую форму записи решения.
- [ФТ-9](../functional/ft-9.md) требует принять проверенную запись до действия.

## Реализация

- [ait-decisions](../../../.apm/skills/ait-decisions/SKILL.md) требует для
  каждого существенного недостатка вариант без него либо доказанное общее
  ограничение.
- [контрольный список](../../../.apm/skills/ait-decisions/references/decision-workflow.md)
  проверяет крайние точки, согласованность доводов, безальтернативность и
  границы раздела «Контекст».
- Постоянный сценарий выявляет общую «дыру» у двух предложенных вариантов.
- Регрессионный сценарий проверяет сокращение многословного контекста без потери
  проблемы и существенных ограничений.

## Проверка

1. Запись решения проходит контрольный список качества до передачи заказчику.
2. Для каждого существенного недостатка указан вариант без него или проверенное
   ограничение, делающее недостаток неизбежным.
3. При общей «дыре» анализ расширяет пространство вариантов и не выбирает между
   заведомо неполными альтернативами.
4. Если ограничение действительно исключает альтернативы, запись честно
   фиксирует безальтернативность и основание, не выдумывая фиктивный вариант.
5. Контекст позволяет понять причину и границы выбора, но не раскрывает
   выбранный вариант, не повторяет соседние разделы и не описывает внутреннюю
   работу агента.
