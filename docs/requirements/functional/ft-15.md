# ФТ-15. Переход от гипотезы к решению

[К списку требований](../../requirements.md)

## Требование

Подтверждение гипотезы становится свидетельством для следующего проектного шага,
но не считается принятым решением. Если следующий шаг содержит значимый выбор,
продукт применяет `ait-decisions` и связывает запись решения и запись гипотезы в
обе стороны.

Опровергнутая гипотеза требует отдельной записи решения только тогда, когда сам
отказ становится значимым проектным решением.

## Основание

[ПТ-5](../user/pt-5.md); решение владельца;
[ADR-0002](../../adr/0002-cross-cutting-decision-records.md) и
[ADR-0005](../../adr/0005-cross-cutting-hypothesis-records.md).

## Связи

- [ФТ-7](ft-7.md) задаёт общую дисциплину записей решений.
- [ФТ-9](ft-9.md) требует принять значимое решение до действия.
- [ФТ-13](ft-13.md) задаёт форму записи гипотезы.

## Реализация

- [ait-hypotheses](../../../.apm/skills/ait-hypotheses/SKILL.md) завершает
  проверку выводом и сохраняет связи.
- [ait-decisions](../../../.apm/skills/ait-decisions/SKILL.md) оформляет
  значимый выбор по полученному свидетельству.
- [ait-routing](../../../.apm/skills/ait-routing/SKILL.md) сохраняет границу
  между подтверждением и решением.

## Проверка

1. Подтверждённая гипотеза не объявляется принятым решением.
2. Значимый выбор создаёт взаимно связанные записи гипотезы и решения.
3. Изменение не выполняется до решения, требуемого правилами целевого проекта.
4. Отрицательный результат не создаёт запись решения без отдельного значимого
   выбора.
