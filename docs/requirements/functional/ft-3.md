# ФТ-3

[К списку требований](../../requirements.md)

## Требование

Продукт подключается к целевому проекту штатными средствами менеджера пакетов
APM.

## Основание

[Концепция](../../concept.md) (подключаемый контур); действующий способ
подключения из [README](../../../README.md).

## Связи

- Обеспечивает подключение продукта заказчиком по [ПТ-1](../user/pt-1.md).
- Явный выбор клиента задан в [ПТ-3](../user/pt-3.md).
- Логический контракт подключения уточнён в [ФТ-4](ft-4.md).
- Число действий заказчика оценивается по [КАЧ-1](../quality/kach-1.md).

## Реализация

- Пакет объявлен в [apm.yml](../../../apm.yml) с целями `claude` и `codex`.
- [README](../../../README.md) содержит команды `apm install` для обеих целей и
  следующий шаг «Настрой проект».
- [ait-setup](../../../.apm/skills/ait-setup/SKILL.md) завершает настройку уже
  установленного продукта в целевом проекте.

## Проверка

1. Команды в README используют пакет `mekras/ai-dev-team`, версию из `apm.yml` и
   ровно одну явную цель: `claude` или `codex`.
2. После установки в целевом проекте есть прямая зависимость
   `mekras/ai-dev-team`, а в выбранном клиенте доступен навык `ait-setup`.
3. `apm run tests` проверяет согласованность команд подключения с версией
   пакета, компиляцию и пробную упаковку.
