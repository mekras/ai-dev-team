# ПТ-7. Полная управляемая проверка репозитория

[К списку требований](../../requirements.md)

## Требование

Заказчик одним явно сформулированным запросом запускает полную проверку целевого
репозитория. Продукт сам определяет применимые специализации, проверяет
репозиторий по всем найденным областям, предлагает исправления и после решения
заказчика доводит исправление и проверку результата до конца.

Заказчику не нужно знать внутренние имена ролей и навыков, составлять перечень
областей или просить агента продолжить после промежуточной сводки. Продукт
останавливается только для решения заказчика или при явном блокере.

Проверяемая область включает отслеживаемые файлы Git и неотслеживаемые файлы,
которые не исключены правилами Git. Внешние системы, окружение компьютера,
служебные данные Git, а также игнорируемые зависимости, кеши и результаты сборки
в область не входят. Проектные команды можно использовать как средство проверки
содержимого репозитория.

Полнота означает применение всех обнаруженных и подходящих проверок к
согласованной области и явное указание непроверенных областей. Требование не
обещает обнаружение любого скрытого дефекта.

## Основание

[БТ-1](../business/bt-1.md), [ПТ-1](pt-1.md) и решения владельца продукта от
2026-07-27. Утверждение `SREQ-065` требует хранить проблемы в отслеживаемом
состоянии, чтобы они не терялись. `SREQ-114` требует проверять влияние изменений
на требования, дизайн, код, тесты, документацию, планы, качество и риски.

## Проверка

1. Явный запрос «Проверь весь проект и исправь все проблемы» запускает
   управляемую полную проверку без требования выбрать внутренние роли и навыки.
2. Общий запрос «Проверь проект» не запускает дорогую полную проверку без
   уточнения намерения.
3. План проверки ограничивает объект файлами из согласованной области и не
   объявляет окружение компьютера либо внешние системы проверенными.
4. Промежуточная сводка не завершает активную проверку и явно сообщает об
   автоматическом продолжении.
5. Итог различает завершение без открытых проблем, завершение с принятыми
   рисками и блокировку.
