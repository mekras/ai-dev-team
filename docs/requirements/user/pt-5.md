# ПТ-5. Регистрация гипотез

[К списку требований](../../requirements.md)

## Требование

Заказчик может зарегистрировать проверяемую гипотезу до принятия решения,
сохранить ход и результат её проверки и найти ранее опровергнутое предложение до
повторного обсуждения.

## Основание

Решение владельца; корпус знаний — `EVAR`, `CHAE`;
[ADR-0005](../../adr/0005-cross-cutting-hypothesis-records.md).

## Связи

- [ФТ-13](../functional/ft-13.md) задаёт отдельную запись и реестр гипотез.
- [ФТ-14](../functional/ft-14.md) сохраняет ход проверки и отрицательный
  результат.
- [ФТ-15](../functional/ft-15.md) отделяет подтверждение гипотезы от решения.

## Реализация

- [ait-hypotheses](../../../.apm/skills/ait-hypotheses/SKILL.md) регистрирует,
  проверяет и сопровождает гипотезы.
- [ait-routing](../../../.apm/skills/ait-routing/SKILL.md) направляет запросы на
  регистрацию и повторное рассмотрение в профильный навык.

## Проверка

1. Запрос до принятия решения создаёт отдельную запись проверяемой гипотезы.
2. Ход и отрицательный результат проверки сохраняются в записи.
3. При повторном предложении продукт находит прежнюю запись и проверяет условия
   пересмотра.
4. `apm run tests` проверяет структуру навыка и его сценарии.
