# Реестр PDR проекта

Product Decision Record (PDR) фиксирует значимые решения о составе и поведении
продукта `ai-dev-team`, которые не относятся только к архитектуре, организации
работы или документации.

Одна запись отвечает на один независимо пересматриваемый вопрос. Для каждой
схемы запись перечисляет её достоинства и недостатки, после чего владелец
решает, включать ли схему в продукт. Решение о конкретной схеме не подменяет
общее требование к продукту.

## Соглашение

- Путь журнала: `docs/pdr/`.
- Идентификатор: `PDR-NNNN`.
- Имя файла: `PDR-NNNN-<краткое-название>.md`.
- Шаблон: MADR с явным сравнением вариантов.
- Реестр сопровождается в этом файле.
- Статусы: `Предложено`, `Принято`, `Отклонено`, `Устарело`, `Заменено`.

Если владелец решает не включать возможность, запись получает статус `Принято`,
а отказ фиксируется как выбранный вариант. Статус `Отклонено` означает, что
предложение записи не принято как решение.

Факторы сравниваются в порядке, установленном правилами проекта: сроки, риски,
стоимость во времени, сопровождение, обратимость и влияние на пользователей или
рабочие процессы.
