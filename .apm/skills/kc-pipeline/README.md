# kc-pipeline

Координирует полный проход корпуса: от учёта и получения первичных данных до
проверки влияния и безопасных правок. Для проектов с повторяемыми запусками
навык также даёт переносимый операционный контур: планирование очередей,
явный запуск проектных команд и адаптеров, пересборку производных индексов и
локальный отчёт. Подробности см. в [договоре операций](references/operations-contract.md)
и [договоре адаптеров](references/adapter-contract.md).
