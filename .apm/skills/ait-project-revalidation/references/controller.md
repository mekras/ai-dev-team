# Контракт продолжения

## Разделение ответственности

Координатор определяет и сохраняет предметное `next_action`. Контроллер хоста
создаёт новый ход, пока связанная цель остаётся активной. Навык не заменяет
контроллер фразой «продолжай автоматически» и не требует отдельной операции
`continue`.

## Проверка доступности

Управляемый режим доступен, если среда позволяет наблюдаемо подтвердить всё
следующее:

1. первоначальный явный запрос связан с долговечной целью
2. цель можно оставить активной после завершения текущего хода
3. хост создаёт следующий ход без новой команды человека
4. сохранённое `next_action` доступно в новом ходе
5. ожидание решения человека приостанавливает продолжение
6. цель завершается только после конечного состояния предметного процесса

Наличие команды, названия режима или возможности возобновить сессию вручную не
доказывает этот контракт.

## Адаптер Codex

Считай адаптер доступным, только если текущий хост предоставляет долговечную
цель и автоматические продолжения активной цели. После промежуточного шага:

1. атомарно сохрани состояние и `next_action`
2. закончи текущий ход
3. не переводи цель в `complete` или `blocked`

Переводи цель в `complete` только после состояния `complete` или
`complete_with_accepted_risks`. Переводи цель в `blocked` только по правилам
самого контроллера и после сохранения предметного блокера.

## Другие клиенты

Для другого клиента примени тот же наблюдаемый контракт. Команда возобновления
сессии годится только для ручного режима, если хост сам не создаёт новый ход.

## Трёхходовое испытание

Положительное испытание:

1. связать запрос с целью и сохранить счётчик `1`
2. оставить цель активной и завершить ход
3. в автоматически созданном ходе восстановить состояние и сохранить `2`
4. снова оставить цель активной и завершить ход
5. в третьем ходе восстановить состояние, сохранить `3` и завершить цель

Доказательство должно содержать три разных хода, переход `1 → 2 → 3` и
отсутствие команды человека между ними.

Сценарий, который завершил цель в первом ходе, не проверяет продолжение.

## Ручной режим

Если контракт не подтверждён, сообщи:

- автоматическое доведение до конца в этой среде не доказано
- состояние сохраняется и позволяет продолжить с точного действия
- для следующего хода человеку потребуется вручную возобновить работу

Не называй ручной режим управляемым и не обещай завершение без команды человека.
