# OWASP GenAI Security Project

Проверено 2026-07-29 по двум точечным единицам:

- `LLM01:2025 Prompt Injection` в каталоге OWASP Top 10 для LLM и генеративных
  приложений;
- обзор Agentic Security Initiative.

## Внедрение инструкций

OWASP описывает внедрение инструкций как уязвимость, при которой
пользовательский ввод изменяет поведение или вывод LLM непредусмотренным
образом. Каталог различает прямое воздействие через запрос и косвенное
воздействие через внешнее содержимое.

## Агентные приложения

Agentic Security Initiative рассматривает автономные агенты и многошаговые
рабочие процессы ИИ. В область инициативы входят системы, которые используют
средства и выполняют последовательности действий.

## Ограничения и охват

Проверены только названные страницы. Остальные публикации и материалы проекта не
извлекались. Каталоги OWASP служат источником угроз и мер, но не заменяют модель
угроз конкретной системы.

Проверяемые фрагменты:

- `user prompts alter the LLM’s behavior or output`;
- `directly or indirectly`;
- `Securing autonomous agents and multi-step AI workflows`.
