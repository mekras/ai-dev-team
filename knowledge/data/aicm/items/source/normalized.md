# AI Controls Matrix v1.1

Проверена официальная страница Cloud Security Alliance 2026-07-29.

## Назначение

AICM v1.1 выпущена 22 июня 2026 года как независимая от поставщика рамка для
облачных ИИ-систем. Страница указывает 247 целей контроля в 18 доменах
безопасности.

Матрица различает роли поставщика модели, оркестрированного сервиса, приложения,
заказчика ИИ и облачного провайдера. Для ролей доступны отдельные рекомендации
по внедрению и аудиту.

## Ограничения и охват

Проверена публичная страница описания. Таблица контролей и материалы,
предоставляемые после загрузки или регистрации, не копировались и не
анализировались.

Проверяемые фрагменты:

- `vendor-agnostic framework for cloud-based AI systems`;
- `247 control objectives distributed across 18 security domains`.
- `Download this Resource`.
