# Markdown

Markdown — облегчённый язык разметки для создания читаемого и удобного для
правки текста, который можно преобразовывать в другие форматы, например HTML.

Источник относит к преимуществам Markdown читаемость исходного текста, простой
синтаксис, поддержку GitHub и Bitbucket, а также многих текстовых редакторов.
Ограничение формата — сравнительно небольшие возможности оформления.
