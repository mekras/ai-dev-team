# Справочник по API

Источник: api.rst.

Справочник API предназначен для разработчиков, использующих API, и должен
давать сведения, необходимые для успешного применения API.

При выборе формата описания API главным фактором выступает вид API. Для API
программного компонента следует рассматривать форматы, принятые для
используемого языка программирования. Если стандартного формата для языка нет,
источник предлагает рассмотреть формат общего назначения.

Сохранённая страница содержит незавершённые разделы об аудитории и процессе
разработки, поэтому рекомендаций для них в нормализованное представление не
включено.
