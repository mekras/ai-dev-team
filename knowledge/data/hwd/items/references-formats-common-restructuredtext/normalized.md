# ReStructuredText

reStructuredText, или ReST, — облегчённый язык разметки для простых веб-страниц,
документов и комментариев в программном коде. Он преобразуется в PDF, HTML,
OpenDocument, LaTeX и другие форматы.

Источник называет преимуществами читаемость исходного текста, простой синтаксис
и поддержку GitHub и Bitbucket. Ограничением остаются возможности оформления.
Для работы с форматом упомянуты Sphinx и Docutils.
