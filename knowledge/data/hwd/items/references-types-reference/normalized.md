# Справочник

Справочник — краткое упорядоченное изложение сведений, рассчитанное на
выборочное чтение. Его назначение — быстрый доступ к главным сведениям по теме и
сохранение знаний в виде памятки.

Статьи справочника должны быть краткими и иметь простую понятную структуру.
Если материала много, источник рекомендует разделять его на несколько статей,
оставляя подробности в отдельных руководствах.
