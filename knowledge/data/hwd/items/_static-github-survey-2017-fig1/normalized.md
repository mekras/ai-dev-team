# Проблемы при работе с открытым исходным кодом

Первичный артефакт: `github-survey-2017-fig1.png`.

Диаграмма ссылается на `opensource.com` и перечисляет проблемы по убыванию
длины столбцов:

1. Неполная или запутанная документация.
2. Отсутствие ответов от разработчика.
3. Пренебрежительные ответы.
4. Конфликты.
5. Отказы без объяснений.
6. Неподходящий язык или контент.

Шкала содержит отметки 0%, 20%, 40%, 60% и 80%. Точные значения для отдельных
столбцов на изображении не напечатаны, поэтому нормализованный слой сохраняет
только их порядок.
