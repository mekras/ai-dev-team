# DDD Reference

Проверена редакция справочника Эрика Эванса от марта 2015 года. Материал
опубликован по лицензии CC BY 4.0. Нормализованы определения модели,
ограниченного контекста, объекта-значения и агрегата, необходимые для
разграничения предметной модели и модели данных.

## Выбранные положения

Модель описывает выбранные стороны предметной области, нужные для решения
задач. Её применимость ограничена контекстом. Ограниченный контекст задаёт
границу, внутри которой определена конкретная модель и действует согласованный
язык.

Объект-значение выражает смысл через атрибуты и поведение, не имеет собственной
идентичности и обычно остаётся неизменяемым. Агрегат объединяет сущности и
объекты-значения внутри границы согласованности. Внешние ссылки направляются на
корень, а инварианты агрегата контролируются как единое целое.
