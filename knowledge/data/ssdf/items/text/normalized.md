# NIST SP 800-218, Secure Software Development Framework

Первичный текст представляет NIST SP 800-218, версию 1.1 Secure Software
Development Framework. Документ подготовлен NIST и опубликован в феврале 2022
года. Он даёт рекомендации по снижению риска уязвимостей программного
обеспечения и доступен по DOI 10.6028/NIST.SP.800-218.

Документ предназначен для добровольного использования также
негосударственными организациями. Указание автора приветствуется.

Полный извлечённый текст сохранён в файле nist-sp-800-218.txt. Дальнейшее
извлечение утверждений должно опираться на карту охвата разделов этого длинного
источника.
