# Gitmoji CLI

## Подготовка сообщения

Официальный интерактивный клиент позволяет искать эмодзи, формировать сообщение
по подсказкам и подключать подготовку сообщения как Git hook. Клиент доступен
через npm и Homebrew.

Наличие клиента снижает объём ручного поиска и настройки, но само по себе не
показывает, насколько широко Gitmoji применяется в проектах.

## Обновление словаря

Команда `gitmoji --update` синхронизирует список эмодзи с репозиторием. При
первом запуске клиент создаёт локальный кеш списка для работы без сети.
