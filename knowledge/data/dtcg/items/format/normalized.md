# Design Tokens Format Module 2025.10

Проверена опубликованная версия спецификации от 28 октября 2025 года.

## Назначение

Документ задаёт формат файла для обмена дизайн-токенами между инструментами.
Дизайн-токены выражают проектные решения независимо от платформы и помогают
поддерживать общий словарь между участниками разработки.

Файлы токенов используют JSON. Для токена обязательны имя и значение. Тип
позволяет инструментам однозначно интерпретировать значение.

## Ограничения и охват

Проверены статус документа, назначение, введение и основные правила формата.
Документ опубликован как итоговый отчёт сообщества, но не является стандартом
W3C.

Проверяемые фрагменты:

- `file format to exchange design tokens`;
- `platform-agnostic way`;
- `Name and value are both required`.
