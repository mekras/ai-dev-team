# Реестр операторов

Проверено 2026-07-18 по порталу персональных данных Роскомнадзора.

Уполномоченный орган ведёт реестр операторов персональных данных. Сведения
реестра, кроме сведений о средствах безопасности, общедоступны. Реестр нужен для
проверки фактического статуса оператора, а не как доказательство соответствия
его обработки всем требованиям закона.
