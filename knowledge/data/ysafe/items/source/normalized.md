# Yandex Cloud AI-SAFE

Проверена публичная страница AI-SAFE 2026-07-29.

## Модель

AI-SAFE распределяет угрозы генеративных технологий по пяти уровням: интерфейс,
исполнение и средства, инфраструктура и оркестрация, ядро и логика, данные и
знания.

Для внедрения инструкций страница рекомендует санитизацию и валидацию входных
данных. Для действий агента через средства она рекомендует минимальные
привилегии и подтверждение человеком критических действий.

## Ограничения и охват

Проверены обзор уровней и два примера мер. Привязки к коммерческим сервисам
Yandex Cloud не переносятся как универсальные требования.

Проверяемые фрагменты:

- `пяти уровнях работы с генеративными технологиями`;
- `Санитизация и валидация входных данных`;
- `human approval gates для критических действий`.
