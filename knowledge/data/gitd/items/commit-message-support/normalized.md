# Git: средства подготовки и проверки сообщений

## Шаблон

Параметр `commit.template` задаёт файл, используемый как шаблон новых сообщений
коммитов.

## Проверка

Git вызывает `commit-msg` при создании коммита. Обработчик может изменить
сообщение, привести его к принятому формату или отклонить коммит ненулевым кодом
завершения. Проверку можно обойти параметром `--no-verify`.
