# Команда агентов для разработки ПО

`ai-dev-team` — подключаемая команда агентов ИИ для разработки ПО. Она
объединяет предметные роли, навыки, правила работы и проверки качества, чтобы
провести задачу от замысла до проверенного результата. Вы задаёте цель,
согласовываете значимые решения и принимаете работу.

Для задачи продукт подбирает нужные роли и навыки, помогает пройти путь от
замысла до проверенного результата и сохраняет значимые решения в документации
проекта.

## Основные возможности

- анализ требований, гипотез и проектных решений
- проектирование архитектуры, интерфейсов и пользовательского опыта
- разработка, рефакторинг, тестирование и обзор кода
- проверки безопасности, надёжности, лицензирования и документации
- работа с корпусом знаний и происхождением проектных сведений
- поиск всех потенциально затронутых частей после изменения и назначение их
  профильных проверок

Полный состав и назначение специализаций описаны в
[обзоре продукта](docs/overview.md) и [справочнике ролей](docs/roles.md).

## Подключение к проекту

Для подключения необходим
[Agent Package Manager](https://github.com/microsoft/apm).

Выберите клиент и выполните команду в корне целевого проекта.

Для Claude:

```shell
apm install mekras/ai-dev-team#^0.22.1 --target claude
```

Для Codex:

```shell
apm install mekras/ai-dev-team#^0.22.1 --target codex
```

После установки откройте выбранный инструмент для общения с агентами в корне
проекта и дайте команду:

```text
Настрой проект.
```

Во время настройки ответьте на вопросы о проекте.

## Работа с проектом

После настройки продолжайте работу в том же выбранном клиенте из корня проекта.
Опишите цель, проблему или ожидаемый результат обычными словами, например:

```text
Нужно сократить время обработки заявки. Изучи текущую реализацию, предложи
решение и после согласования внеси изменения.
```

Продукт сам подберёт специалистов, выполнит работу и покажет результат,
проведённые проверки и оставшиеся ограничения.

### Полная проверка проекта

Для периодической перепроверки всего репозитория дайте агенту команду:

```text
Проверь весь проект и исправь все проблемы.
```

Продукт сам подберёт применимые проверки. Подробное описание находится в
[требовании к полной проверке](docs/requirements/user/pt-7.md).

## Обновление продукта

Когда выходит новая версия продукта, сначала обновите зависимость для того же
клиента, который выбрали при подключении.

Для Claude:

```shell
apm update mekras/ai-dev-team --target claude
```

Для Codex:

```shell
apm update mekras/ai-dev-team --target codex
```

Затем в корне проекта дайте агенту команду:

```text
Обнови проект под новую версию ai-dev-team.
```

Агент прочитает разделы «Действия при обновлении» для всех пропущенных версий,
покажет их списком и проведёт по каждому применимому действию. Отдельно
запускать названные в журнале навыки не нужно.

Что изменилось между версиями, описано в [журнале изменений](CHANGELOG.md).
